# Municipalidad de Cholchol - Rediseño Web

Proyecto académico desarrollado para la asignatura de Desarrollo Frontend.

Este proyecto consiste en el rediseño de la página web de la Municipalidad de Cholchol, utilizando tecnologías frontend modernas y diseño responsive.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bulma CSS
- Font Awesome

---

## Características del proyecto

- Diseño responsive para móviles y escritorio
- Navbar con menú hamburguesa funcional
- Hero principal institucional
- Sección de noticias destacadas
- Carrusel de imágenes
- Formulario con validaciones en JavaScript
- Herramientas básicas de accesibilidad
- Animaciones y efectos visuales
- Organización modular de archivos CSS
